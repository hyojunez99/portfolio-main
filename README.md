# Portfolio Main Website

## 1. 프로젝트 소개

- **설명:**  
  개인 개발 역량과 작업 스타일을 효과적으로 보여주기 위해 제작한 포트폴리오 웹사이트입니다.  
  React 기반 SPA 구조로 구성했으며, 사용자 경험을 고려한 인터랙티브 UI/UX와 스크롤 애니메이션을 중심으로 설계했습니다.  
  직관적인 정보 탐색과 시각적 임팩트를 통해 방문자에게 기억에 남는 경험을 제공하는 것이 목표입니다.

- **진행 기간:** 2026.01.19 ~ 2026.02.02 (약 3주)
- **개발 인원:** 개인 프로젝트
- **배포 링크:** [Portfolio Main](https://hyojunez99.github.io/portfolio-main/)

---

## 2. 사용 기술 스택 (Tech Stack)

- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Framework & Library:** React.js
- **Styling & Animation:** SCSS, GSAP
- **Data Handling:** JSON (Mock Data)
- **Design Tools:** Figma, Photoshop, Illustrator
- **Collaboration & Dev Tools:** Git, GitHub

---

## 3. 기획 및 디자인 (Planning & Design)

- **컨셉:**
  - 방문자가 포트폴리오를 탐색하며 자연스럽게 경험할 수 있는 직관적 UI/UX
  - 섹션 단위 스크롤과 애니메이션으로 시각적 임팩트 제공
  - 개인 키워드 기반 메시지 전달 ("도전하는 자가 아름답다", "자신감", "끝까지 구현")

- **Tool:** Figma
- **주요 활동:**
  - 전체 와이어프레임 제작 및 프로토타입 설계
  - 색상, 타이포그래피, 컴포넌트 스타일 가이드 정의
  - 섹션별 콘텐츠 구조 설계 및 사용자 동선 기획

## 6. 주요 기능

- JSON 데이터를 기반으로 프로젝트, 스킬, 소개 정보 자동 렌더링
- 섹션별 스크롤 애니메이션으로 자연스러운 정보 전달
- Header, Footer, 버튼 등 UI 컴포넌트 분리
- 모바일 375px부터 데스크톱까지 모든 해상도 대응
- 단어별 메시지 순차적 등장, 파동 효과 스크롤 아이콘

## 7. 트러블 슈팅

문제 1 : 백그라운드 동영상 자동 재생 불가

해결 : 동영상이 자동으로 재생되지 않는 문제를 해결하기 위해, 동영상을 소리 없이 자동 재생되도록 설정하고, 모바일에서는 화면이 비어 보이지 않도록 기본 이미지를 보여주도록 수정함.

문제2 : 프로젝트 상세 페이지에서 PDF 파일을 링크로 연결했으나, 일부 브라우저에서 새 탭으로 열리지 않거나 다운로드가 되지 않는 현상이 발생함.

해결 : PDF 파일 링크를 새 탭에서 열리도록 설정하고, 브라우저에서 안전하게 열리도록 속성을 추가함. 또한 서버 설정을 확인해 PDF가 정상적으로 열리도록 수정함.
