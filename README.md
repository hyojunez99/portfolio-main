# 개인 포트폴리오 웹사이트 (Portfolio Main Website)

## 1. 프로젝트 소개

- **설명:**  
  개발 역량과 작업 스타일을 명확하게 전달하기 위해 **기획·디자인·개발 전 과정을 직접 수행**한 개인 포트폴리오 웹사이트입니다.  
  React 기반 SPA 구조로 구성했으며, **GSAP 스크롤 애니메이션과 인터랙티브 UI/UX**를 중심으로 설계했습니다.  
  직관적인 정보 전달과 시각적 임팩트를 통해 방문자에게 기억에 남는 경험을 제공하는 것이 목표입니다.

- **진행 기간:** 2026.01.19 ~ 2026.02.02 (15일)  
- **개발 인원:** 개인 프로젝트  
- **배포 링크:** [Portfolio Main](https://hyojunez99.github.io/portfolio-main/)  
- **GitHub 저장소:** [hyojunez99/portfolio](https://github.com/hyojunez99/portfolio.git)  

---

## 2. 사용 기술 스택 (Tech Stack)

- **Frontend:** JavaScript (ES6+), React.js, SCSS  
- **Data Handling:** Mock JSON  
- **Animation:** GSAP  
- **Design & Tools:** Figma, Photoshop, Illustrator, Git/GitHub  

---

## 3. 기획 및 디자인

- **컨셉:**  
  - 방문자가 자연스럽게 포트폴리오를 탐색하며 경험할 수 있는 직관적 UI/UX  
  - 섹션 단위 스크롤 애니메이션으로 시각적 임팩트 제공  
  - 프로젝트별 메시지와 기술 스택 강조  

- **활동:**  
  - 전체 와이어프레임 제작 및 프로토타입 설계  
  - 색상, 타이포그래피, 컴포넌트 스타일 가이드 정의  
  - 섹션별 콘텐츠 구조 설계 및 사용자 동선 기획  

---

## 4. 주요 기능

- JSON 데이터를 기반으로 프로젝트, 스킬, 소개 정보 자동 렌더링  
- GSAP 스크롤 애니메이션과 인터랙티브 UI 구현  
- Header, Footer, 버튼 등 공통 컴포넌트 분리  
- 반응형 웹 구현 (데스크톱, 태블릿, 모바일 대응)  
- 프로젝트 카드, 기술 스택, 상세 페이지 모달 등 정보 집중형 UI 구성  

---

## 5. 트러블 슈팅 (Troubleshooting)

| 문제 | 해결 | 주요 키워드 |
|------|------|------------|
| 프로젝트 카드 레이아웃이 다양한 화면 크기에서 일관되지 않음 | Flex 기반 구조를 Grid로 변경하고 Media Query 적용, 컬럼 수 자동 조정 | 레이아웃, Grid, Media Query |
| PDF 파일 링크가 브라우저별로 새 탭에서 열리지 않음 | 링크 속성 수정 및 브라우저별 테스트 진행 | 브라우저, 새 탭, 링크 속성 |
| 모바일 환경에서 100vh 섹션이 주소창 표시 여부에 따라 화면이 잘리거나 어긋남 | min-height 중심으로 레이아웃 수정, 콘텐츠 스크롤 구조 개선 | 100vh, 모바일 환경, min-height |

## 6. 개발 후 느낀점 (Insights)

- 기능 구현보다 **전체 구조를 먼저 고민하는 것**이 중요함  
- 애니메이션 적용 시 **사용자 흐름을 방해하지 않는 선**에서 자연스럽게 적용해야 함  
- 프로젝트를 진행하며 **UI/UX 설계와 React 구조 설계의 균형**을 배우고, 유지보수와 확장성을 고려하는 습관을 갖게 됨
