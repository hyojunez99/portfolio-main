# Portfolio Main Website

- **설명:**  
  개발 역량과 작업 스타일을 명확하게 전달하기 위해 기획·디자인·개발 전 과정을 직접 수행한 개인 포트폴리오 웹사이트입니다.

- **진행 기간:** 2026.01.19 ~ 2026.02.02 (15일)
- **개발 인원:** 개인 프로젝트
- **배포 링크:** [Portfolio Main](https://hyojunez99.github.io/portfolio-main/)
- **GitHub:** [Repository Link](https://github.com/hyojunez99/portfolio.git)

## 2. 사용 기술 스택 (Tech Stack)

- **Frontend:** JavaScript (ES6+), React.js, SCSS
- **Data Handling:** Mock JSON
- **Animation:** GSAP
- **Design Tools:** Figma, Photoshop, Illustrator
- **Version Control & Tools:** Git, GitHub

- **Tool:** Figma
- **주요 활동:**
  - 전체 UI/UX 설계 및 레이아웃 디자인

  - 반응형 웹 구현 설계 (데스크탑, 태블릿, 모바일)

## 6. 주요 기능

- GSAP을 활용한 인트로 텍스트 및 스크롤 인터랙션 애니메이션
- 섹션별 목적에 맞는 UI 구성과 정보 전달 중심의 레이아웃
- 데스크탑·태블릿·모바일 환경 대응 반응형 웹
- 프로젝트 데이터를 JSON 기반으로 관리하여 유지보수 용이성 확보

## 7. 트러블 슈팅

- **문제 1:** 프로젝트 카드 레이아웃을 다양한 화면 크기에서 일관되게 유지하기 어려움
  - **해결:** Flex 기반 구조를 Grid로 변경하고 Media Query를 활용해 모바일, 태블릿, 데스크톱에서 컬럼 수가 자연스럽게 변경되도록 구성

- **문제 2:** PDF 파일을 링크로 연결했을 때 브라우저에 따라 새 탭으로 열리지 않는 문제
  - **해결:** 링크 속성을 수정하고 여러 브라우저에서 테스트하며 동작 차이를 확인

- **문제 3:** 모바일 환경에서 100vh 섹션이 주소창 표시 여부에 따라 화면이 잘리거나 어긋나는 문제
  - **해결:** 고정된 높이 대신 min-height 중심으로 레이아웃 수정, 콘텐츠가 자연스럽게 스크롤되도록 구조 개선
